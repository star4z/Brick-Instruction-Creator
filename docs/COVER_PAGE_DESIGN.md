# Front Cover Page — Official LEGO-Style Editorial Design Specification

## 1. Overview & Goals

The front cover of a manual generated by **Brick Instruction Creator** follows the clean, editorial composition of modern official LEGO instruction booklets:

- **Minimal, uncluttered page canvas** inheriting the active theme (or optional user-uploaded background image) with generous visual breathing room.
- **High-quality, page-filling hero 3D render** of the completed model centered across the page, framed with camera-space tight bounding-box projection, studio 3-point + ABS plastic specular shading, refined seam lines, and a camera-accurate soft studio floor shadow.
- **Top-left identity column**:
  - Optional **Creator Logo** image uploaded by the builder, positioned cleanly above the title.
  - **Model Name** in bold editorial typography directly below the creator logo (or at top-left if no logo is set).
  - **Optional Subtitle** directly underneath the model name (rendered only when non-empty).
- **Top-right theming slot**:
  - Optional **Theming Image** (such as a series badge, theme wordmark, or faction emblem), right-aligned at the top-right corner.
- **Bottom-right program attribution & QR code**:
  - **Brick Instruction Creator** icon and name paired with a scannable **QR code** (toggleable, enabled by default) pointing to `https://star4z.github.io/Brick-Instruction-Creator/`.
  - **Clickable in both live preview and exported PDF**: in the live viewer it opens in a new tab without triggering page panning; in the exported PDF it embeds a standard PDF 1.4 `/Subtype /Link` URI annotation over the badge and QR code bounding box.

## 2. Layout Architecture

Both the live HTML preview (`src/studioRuntime.ts`) and the high-DPI PDF canvas renderer share a single deterministic layout calculator in [`src/cover/coverLayout.ts`](../src/cover/coverLayout.ts).

```
┌────────────────────────────────────────────────────────────────┐
│ [Creator Logo]                                 [Theming Image] │
│ Model Name                                                     │
│ Optional Subtitle                                              │
│                                                                │
│            ╔══════════════════════════════════════╗            │
│            ║                                      ║            │
│            ║    High-Quality Page-Filling Hero    ║            │
│            ║      3D Model Render + Soft Floor    ║            │
│            ║            Studio Shadow             ║            │
│            ║                                      ║            │
│            ╚══════════════════════════════════════╝            │
│                                                                │
│                                    [Icon + Name]  [ QR Code ]  │
└────────────────────────────────────────────────────────────────┘
```

### Zone Proportions
- **Outer Margin (`pad`)**: ~4.8% of the page's shorter dimension (respecting print safety margins).
- **Top-Left Column**: Max width ~46% of inner width.
  - Creator Logo (optional): max height ~9.2% of page height, max width ~24% of page width, aspect-ratio preserved (`contain`, left-aligned).
  - Model Name: bold editorial sans-serif (~3.8%–4.2% of page height), wraps gracefully up to 2 lines.
  - Subtitle (optional): muted weight (~1.8% of page height), omitted entirely when blank.
- **Top-Right Theming Image**: Optional, max height ~11.5% of page height, max width ~42% of page width, aspect-ratio preserved (`contain`, right-aligned).
- **Hero Render Region**: Spans ~94% of page width (`left: 3%`, `right: 3%`) and ~78%–82% of page height (`top: ~11%–15%`, `bottom: ~7%`), sitting cleanly behind the corner overlays (`z-0` vs `z-10`) so tall masts, antennae, or wings can rise naturally into the open center space between the top-left and top-right headers.
- **Bottom-Right Program Attribution & QR Code**:
  - Anchored to bottom-right `(right: pad, bottom: pad)`.
  - QR code square card: side length ~8.8% of page height (approx. 18–20 mm on US Letter/A4), white background with quiet zone and subtle border for universal camera scannability on both light and dark themes.
  - Program badge: matching height rounded pill/card containing the official 3-wave arrow logo mark and stacked `"Brick Instruction\nCreator"` label.
  - Combined bounding rectangle is registered as a clickable link in both DOM (`<a>`) and PDF (`/Annot /Subtype /Link`).

## 3. High-Quality Hero Rendering Pipeline

To achieve a publication-grade cover render inside the pure-JS WebGL engine (`WebGLBrickEngine` in `src/studioRuntime.ts`):

1. **Camera-Space Tight Bounding-Box Projection (`tightFit: true`)**:
   - Instead of orthographic bounding-sphere framing (which leaves large dead margins on elongated ships, trains, or towers), every mesh vertex is projected onto the camera's `(right, up, forward)` basis vectors to compute the exact screen-space bounding box.
   - The orthographic frustum is re-centered on the projected midpoint and fitted to the hero canvas aspect ratio with ~4% breathing room, scaled by the user's optional `coverMeta.zoom` multiplier (`0.75`–`1.35`).
2. **Hero Studio Lighting (`heroShading: true`)**:
   - Uses camera-relative 3-point studio lighting (overhead key, warm opposite fill, subtle rim highlight for dark bricks) plus a Blinn-Phong specular highlight (`pow(dot(N, H), 42)`) simulating injection-molded ABS plastic sheen.
   - Brick edge lines render with softened opacity on the cover so brick seams read as refined micro-bevels rather than heavy technical CAD strokes.
3. **Soft Studio Ground Shadow (`heroShadow: true`)**:
   - Projects the model's grounded base footprint (`y = minY`) and full horizontal XZ silhouette onto the floor plane through the exact camera MVP matrix.
   - Composites dual-layer soft radial ellipses (ambient cast shadow + tighter contact shadow directly under grounded supports) beneath the high-resolution WebGL model render.
4. **High Resolution & Caching**:
   - Live cover preview renders up to `1600px` wide (aspect-matched to the hero zone) and caches by `(model, az, el, zoom, themeId, size)` so typing titles or toggling branding is instantaneous.
   - PDF export renders up to `2000px` wide for crisp print output.

## 4. Pure-TypeScript QR Code Generator (`src/cover/qrCode.ts`)

- Zero external dependencies (Neocities-safe, tiny bundle footprint).
- Implements ISO/IEC 18004 Byte-mode QR encoding (Versions 1–6, EC levels `L` and `M`) with GF(256) Reed-Solomon error correction, interleaved blocks, finder/alignment/timing patterns, 15-bit BCH format information, and all 8 mask evaluations with standard penalty scoring.
- Encodes `https://star4z.github.io/Brick-Instruction-Creator/` (52 bytes) into a crisp **Version 4-M** (33×33 modules, 15% error correction) QR code rendered as a single-path SVG in the DOM and sharp pixel-aligned rectangles in the PDF canvas.

## 5. Clickable PDF Link Annotations (`src/export/pdfBinary.ts`)

The pure-JS PDF 1.4 binary builder supports per-page URI link annotations (`PdfPageLink`):

- Each link rectangle in top-left canvas pixel coordinates `(x, y, w, h)` is converted to PDF bottom-left point coordinates `[llx, lly, urx, ury]`.
- Page objects with links emit `/Annots [ <annotId> 0 R ... ]`, and each annotation object writes:
  ```pdf
  << /Type /Annot /Subtype /Link /Rect [llx lly urx ury] /Border [0 0 0] /H /I /A << /Type /Action /S /URI /URI (https://star4z.github.io/Brick-Instruction-Creator/) >> >>
  ```
- Applied to the bottom-right program logo + QR badge on the Front Cover, as well as the program logo on the Back Cover.

## 6. Data Model & Persistence

`coverMeta` (persisted in undo history, IndexedDB session preferences, and `.bic.json` project exports):

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `string` | `''` (falls back to `model.title`) | Model name shown at top-left |
| `subtitle` | `string` | `''` (hidden when empty) | Optional subtitle below model name |
| `az` | `number` | `34` | Hero camera azimuth in degrees |
| `el` | `number` | `18` | Hero camera elevation in degrees |
| `zoom` | `number` | `1.0` | Hero render scale (`0.75`–`1.35`) |
| `bgSrc` | `string \| null` | `null` | Optional full-page background image data URL |
| `creatorLogoSrc` | `string \| null` | `null` | Optional creator logo image above model name (top-left) |
| `themeImageSrc` | `string \| null` | `null` | Optional theming image (top-right) |
| `showQrCode` | `boolean` | `true` | Show scannable QR code next to program badge (bottom-right) |
| `showProgramBadge` | `boolean` | `true` | Show program icon & name in bottom-right |
