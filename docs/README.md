# Design Documentation

All architecture specifications and feature design proposals for **Brick Instruction Creator** are stored in this `docs/` directory as living documents and updated as features evolve.

## Documents

- [`ARCHITECTURE.md`](./ARCHITECTURE.md) — Core system architecture, invariants, data model, algorithms, and deployment constraints.
- [`COVER_PAGE_DESIGN.md`](./COVER_PAGE_DESIGN.md) — Official LEGO-style front cover, Build Complete & back cover layout, non-editable Brick Instruction Works attribution ("Made with", unified brand title, QR action caption, and fixed back cover credit), page-filling hero 3D render pipeline with Cube+Camera angle presets (`4°..60°`) + zoom, pure-TS QR code generator, and clickable PDF link annotations.
- [`SUBDIVISION_DESIGN.md`](./SUBDIVISION_DESIGN.md) — Large & elongated model subdivision suggestions on import (2D PCA halves, modular floors, natural sub-assemblies, footprint quadrants, Split by Baseplate, custom Build Organization listbox picker with inline descriptions, and 3D exploded import assistant with always-visible overlay controls).
- [`MINIFIG_POSE_DESIGN.md`](./MINIFIG_POSE_DESIGN.md) — Standing upright minifigure normalization, default arm positioning (with purse/satchel/clearance exceptions), and pre-placement posing.
- [`MINIFIG_STEP_STYLES_DESIGN.md`](./MINIFIG_STEP_STYLES_DESIGN.md) — Official LEGO minifigure instruction styles: Exploded Stack Callout (vertical white box, red arrows, horizontal connector, accessory callouts) and Sequential Step-by-Step (numbered sub-steps, blue arrows, multi-part accessory pill, completion starburst), neck-stud-centered stacking arrows, and front-facing accessory previews.
- [`PART_TEXTURES_DESIGN.md`](./PART_TEXTURES_DESIGN.md) — BrickLink Studio `PE_TEX_PATH`/`PE_TEX_INFO` and LDraw `!TEXMAP`/`!DATA` embedded PNG decal pipeline, synchronous pre-decoding, direct RGB colors, and WebGL PBR/step compositing for minifigure faces and printed parts.
- [`LDR_IMPORT_DESIGN.md`](./LDR_IMPORT_DESIGN.md) — Automatic LDraw (`.ldr`/`.mpd`) part shape & `!TEXMAP` texture downloading on import and session restore, CORS mirror failover, MPD parser normalization, `~Moved to` title resolution, extended LDConfig color support, and BrickLink Studio part-origin corrections (e.g. `93091` handbag).
- [`BRICKS_LIBRARY_DESIGN.md`](./BRICKS_LIBRARY_DESIGN.md) — Dedicated Bricks Library screen linked from the menu: bundled searchable Online Parts Catalog (~29.7k official + unofficial/Studio parts fetched on demand), searchable 3D parts preview & multi-angle inspector, top-level parts vs subparts/primitives classification, context-aware model fetch, official + unofficial/Studio source selector, curated online starter packs, local `.zip`/`.dat` import, and clearly separated 2-step Saved Library clearing.
- [`IMPORT_MISSING_PARTS_DESIGN.md`](./IMPORT_MISSING_PARTS_DESIGN.md) — Pre-import missing parts & printed decal detection and inline fetch prompt shown before subdivision analysis and the Step Generation Wizard.
- [`INTERACTIVE_HTML_EXPORT_DESIGN.md`](./INTERACTIVE_HTML_EXPORT_DESIGN.md) — Self-contained offline Interactive 3D HTML instruction viewer export with deduplicated WebGL part meshes, embedded decals, free 360° orbit/pan/zoom on all 3D pages (including Cover & Build Complete), and direct link back to the Studio editor.
- [`PAGE_LAYOUT_GROUPS_DESIGN.md`](./PAGE_LAYOUT_GROUPS_DESIGN.md) — Expanded paper format dropdown with live paper proportion preview, orientation box icons, LEGO-style step divider lines (`Lines` / `Boxes` / `None`, defaulting to `Lines` with column-first step flow and orientation-based guillotine line priority + T-junction gaps across live preview, Page Setup preview, and PDF export), physical Smart Auto Grid packing (minimum 1″ × 1″ step area + margins, 1 stud ≥ 0.5 cm with zero 1–2 step cap, and verified 1-up top-left PLI header-height reclamation), regular Model Issues & Page Setup larger-page warnings for physical print formats (silent on default Screen Fit), customizable grids with steps per page derived from the layout & page breaks, mixed layouts, visual density/page-number guides, booklet outside-edge (recto/verso) page number positioning across Live Preview & PDF/Print export, and editable Step Range Groups.
- [`DYNAMIC_STEP_SIZING_DESIGN.md`](./DYNAMIC_STEP_SIZING_DESIGN.md) — Cognitive-budget dynamic bricks-per-step sizing (structured rows/grids/pairs vs. scattered texture, even-chunk splitting, gentle Step 1 opening, opposite-wall guards) and sticky camera-corner selection with camera-aware frontier ordering.
- [`CONCAVE_CONTACT_AND_SUPPORT_DESIGN.md`](./CONCAVE_CONTACT_AND_SUPPORT_DESIGN.md) — Local concave sub-box collider from compiled `.dat` geometry, two-phase physical clutch verification, top-hung-safe vertical prerequisites, and zero-floating step invariants.
- [`STEP_EDITOR_UX_DESIGN.md`](./STEP_EDITOR_UX_DESIGN.md) — Scope-based bottom dock (`Pan | Parts | Step | Page`, `Pan | Camera | Page`, `Pan | Page`), clicking blank stage space outside the document to return to `Pan`, live compact floating cards, unified Cover/Complete/Step 3D camera controls (Cube+Camera icons, Zoom, plus live drag-to-orbit on step pages), 3-tier scope badges (`local`, `range`, `manual`), step-bound custom callouts, Apply Camera to Steps dual-handle range dialog with optional zoom/framing copy, Pages & Steps live HiDPI preview thumbnails, mobile zoom auto-hide, and unified Step Generation menu & modal.
- [`CUSTOM_FILE_EXTENSIONS_DESIGN.md`](./CUSTOM_FILE_EXTENSIONS_DESIGN.md) — Dedicated `.biw` project and `.biwtheme` custom theme file extensions, `brick-instruction-works-*` payload format headers, file/payload validation, and Safari/iOS extension preservation.
- [`TERMINOLOGY.md`](./TERMINOLOGY.md) — UI wording convention: "parts" for elements and all counts in the editor, "pcs" only on printed manual pages, "brick" only for the category and product names.
- [`ABSOLUTE_STEP_NUMBERING_DESIGN.md`](./ABSOLUTE_STEP_NUMBERING_DESIGN.md) — Printed (per-submodel) vs absolute (manual-wide, unique) step numbers; all step ranges (camera angle, Step Range Groups, overview selection) use absolute numbers, both shown in the UI, with legacy group migration.
- [`THEME_FONTS_DESIGN.md`](./THEME_FONTS_DESIGN.md) — Customizable theme fonts: heading vs body font roles, 18-font self-hosted WOFF2 catalog across 4 categories (Sans & Geometric, Technical & Sci-Fi, Editorial & Slab, Display & Playful), custom `.ttf`/`.otf`/`.woff2`/`.woff` font uploads persisted in IndexedDB and embedded in `.biwtheme`/`.biw`/HTML exports, visual font picker with live specimens & search, and consistent DOM / PDF canvas / interactive HTML rendering.
- [`STYLE_DIALOG_THEMES_DESIGN.md`](./STYLE_DIALOG_THEMES_DESIGN.md) — All theme editing inline in the Style dialog: sticky recency-ordered horizontal theme strip header (current first), auto-fork of built-in themes on edit, New from Current, step display & Parts List options stored on themes with legacy migration, and single-file `.biwtheme` export (iOS share "2 Items" fix).
- [`STEP_RENDER_RESOLUTION_DESIGN.md`](./STEP_RENDER_RESOLUTION_DESIGN.md) — High-resolution step page model rendering: slot-aspect-aware HiDPI sizing, zoom-aware in-place sharpening, supersampled print-ready (~180 DPI) PDF export, mipmapped/anisotropic decal filtering, and smoother curved procedural brick geometry.
- [`PARTS_LIST_DESIGN.md`](./PARTS_LIST_DESIGN.md) — Customizable dense & automatic page-filling Parts List grids, strict integer grid-multiple variable part sizing, all 8 directional grid flows (rows/columns × LTR/RTL × TTB/BTT), alternative Table format, unified draggable Columns & Item Fields (including LEGO Part ID & Color swatches), sticky live layout preview header, live SVG visual indicators, and theme-level persistence.
- [`STEP_CAMERA_STABILITY_DESIGN.md`](./STEP_CAMERA_STABILITY_DESIGN.md) — Occlusion-driven step camera selection with readability deadband, page-aspect-aligned canonical 3/4 angles & layout-aware minifigure cameras, exact per-part 2D projected framing with visual centering, 1-up top-left PLI clearance shifts, readability-aware auto regional focus with 2D bounds clamping, global Viterbi DP sequence smoothing, tall foreground panel deferral, and live free-orbit & continuous-section rotation indicator synchronization.
- [`WORDLESS_INSTRUCTIONS_DESIGN.md`](./WORDLESS_INSTRUCTIONS_DESIGN.md) — LEGO-style Wordless Instructions mode (default on new imports, summarized in the Import Wizard and toggleable anytime in Page Setup), universal iconography across Live Preview, PDF export, and Interactive 3D HTML export, and configurable per-surface text visibility (Front Cover title, Build Complete, and Parts List names/colors).
- [`IMPORT_WIZARD_DESIGN.md`](./IMPORT_WIZARD_DESIGN.md) — Dedicated read-only Import Wizard showing clean project-level defaults (Slicing, Theme, Text & Labels/Wordless, Rendering Style, Page Format) linking to project-level editable pages with top-left back navigation before steps are rendered, with Step Generation focused strictly on slicing.
- [`APP_SETTINGS_DESIGN.md`](./APP_SETTINGS_DESIGN.md) — App-wide Settings page (`#settingsModal`) persisted in `localStorage`: New Manual Defaults (`Built-in` / `Custom Defaults` / `Remember Last Used` + `Copy from Current Project`), Import Wizard prompt mode (`Always` / `When Needed` / `Never`), Default Creator Logo & Cover Subtitle, Measurement Units (`in` / `cm`), Desktop Side Menu startup (`Expanded` / `Collapsed` / `Remember`), Missing Parts policy (`Ask First` / `Fetch Automatically` / `Never Fetch`), and Reset Settings.
- [`DESTRUCTIVE_ACTIONS_DESIGN.md`](./DESTRUCTIVE_ACTIONS_DESIGN.md) — Three-tier destructive action UX: zero warnings for undoable on-screen actions, strictly conditional inline amber notices beside controls that overwrite/clear/shift edits made elsewhere (Apply Camera to Steps, customized Wordless toggles, post-import Step Generation, customized Step Merge, Parts Mode all-selected Move to Step, overlapping Step Range Groups), and a unified "Are you sure?" confirmation dialog (`#confirmActionModal`) for permanent non-undoable actions (Close Model, Replace Model with unsaved edits, Delete Custom Theme, Bricks Library removal & clear).
- [`KEYBOARD_SHORTCUTS_DESIGN.md`](./KEYBOARD_SHORTCUTS_DESIGN.md) — Cross-platform keyboard controls for Undo/Redo (`Ctrl/⌘+Z`, `Ctrl/⌘+Shift+Z`, `Ctrl+Y`), page navigation, zoom, editor modes, step/hero camera rotation & flip, page breaks, Parts nudging, panel/file dialogs, hierarchical `Escape` dismiss, dynamic tooltips, and inline customizable Keyboard Shortcuts section in the Main Menu (`localStorage`-persisted sparse overrides with conflict resolution).
- [`SIDE_MENU_DESIGN.md`](./SIDE_MENU_DESIGN.md) — Unified top-left menu toggle, site title, and collapsible side menu (`#menuDrawer`): expanded by default on desktop (`>= 1024px`) as a docked non-obstructing left panel reserving `#workspaceArea` width, seamlessly combining with the menu button and `Brick Instruction Works` title in place instead of replacing them, with overlay scrim dismissal on tablet/mobile.
- [`STAGE_GESTURES_DESIGN.md`](./STAGE_GESTURES_DESIGN.md) — Zero-jitter native touch stage gestures including Procreate-style Quick Pinch to Fit ("pinch to fill") with velocity/hold/rebound classification, staggered finger-lift guarding, and cancelable cubic ease-out snap-to-fit animation.
- [`UNDERSIDE_ASSEMBLY_AND_SMOOTH_PRIMITIVES_DESIGN.md`](./UNDERSIDE_ASSEMBLY_AND_SMOOTH_PRIMITIVES_DESIGN.md) — High-resolution 48-segment LDraw circular primitive substitution with cylinder silhouette edges, general Primary Structural Deck & upside-down underside pocket assembly (`flip_vertical`), pre-built Technic axle/bar mechanism sub-assemblies, and domain-neutral wheel assembly naming.
- [`PLACEMENT_ARROWS_DESIGN.md`](./PLACEMENT_ARROWS_DESIGN.md) — LEGO-authentic automatic placement arrows & offsets (disabling default new-part outline highlighting, always offsetting attached pieces on Step 1, detecting lateral insertions / occlusion / color camouflage / small details on subsequent steps, single vs. dual end-aligned crimson 3D arrows, and live / PDF / Interactive 3D HTML rendering).
- [`OFFICIAL_MANUAL_CRAFT_DESIGN.md`](./OFFICIAL_MANUAL_CRAFT_DESIGN.md) — Official manual craft enhancements synthesized from LEGO 31172 (2025) and 75192 (UCS): perceptual contrast-adaptive placement arrows (green on red), luminance-aware light edge lines on dark bricks, shape-specific circled `(N)` vs. squared `[N]` length badges & true-scale orthographic 1:1 silhouettes, 1:1 coaxial assembly-position callouts, orthogonal/forked callout leader routing, chiral mirrored subassembly pairing, attachment starbursts & curved yellow articulation arrows, Visual Build Roadmap & bottom-edge progress bar, Technical Gray theme preset, regional cropped close-up framing, relative-scale variable-width BOM masonry, and Ctrl+F searchable PDF metadata + Interactive HTML Part Finder.
- [`UI_E2E_TESTING_DESIGN.md`](./UI_E2E_TESTING_DESIGN.md) — Automated Playwright E2E UI & feature audit suite running against Desktop (`1280×800`) and Mobile (`390×844`) layouts on every update, checking all pages, modals, drawers, popovers, overflow, clipping, overlapping chrome, and zero console/page errors.
- [`PAGE_RENDER_CACHING_DESIGN.md`](./PAGE_RENDER_CACHING_DESIGN.md) — Zero-encode offscreen `<canvas>` mounting, pixel-budget LRU page/minifig/1:1 caching (`src/engine/pageRenderCache.ts`), official minifigure wasted-snapshot elimination & adaptive sub-render supersampling, `pageNavigationOnly` fast path, PLI thumbnail ordering, direct PDF canvas drawing, and paint-aware adjacent-page idle pre-warming.

## Conventions

- Every new feature design proposal or architectural spec should be committed under `docs/` (e.g., `docs/<FEATURE>_DESIGN.md`) and listed in this index.
- Keep existing design documents up to date when requirements, algorithms, or implementation phases change.
